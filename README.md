# UQ Space Decision Matrix

An automated engineering Decision-Making Matrix (DMM) designed to improve
the consistency and effectiveness of engineering design decisions using the
Analytic Hierarchy Process (AHP) and TOPSIS.

## Project Status

- [x] AHP criterion weighting
- [x] AHP consistency validation
- [ ] TOPSIS implementation

- [ ] Web interface
